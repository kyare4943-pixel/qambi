# 🎬 Qambi Filims - 3D Cinema Showcase & Platform

Website casri ah oo loogu talagalay daawashada iyo soo bandhigidda filimada, oo leh waji hore (Home) **3D Three.js** ah, raadin toos ah (Live Search), shaandheynta sanadaha (Year Filter), iyo foom lagu soo geliyo filimo cusub oo leh faahfaahin, taariikh, iyo sawirro.

---

## 🌟 Tilmaamaha Muhiimka ah (Features)

1. **Wajiga Hore ee 3D-ga ah (Interactive 3D Hero)**:
   - Three.js 3D cylindrical carousel oo filimada caanka ah 3D ahaan ugu wareegaya.
   - Iftiinka shineemada (Neon Red & Gold lights) iyo 700+ particles oo hawada ku sabeynaya.
   - Parallax camera oo raacaya dhaqdhaqaaqa jiirka (mouse).
   - Kaararka oo 3D ahaan u leexanaya (3D tilt on mouse hover).

2. **Nidaamka Raadinta (Instant Live Search)**:
   - Baar filimada adoo adeegsanaya Magaca filimka, Sheekada/Faahfaahinta, Sanadka, Nooca (Genre), ama Jilayaasha.

3. **Shaandhaynta Sanadka (Year Filter)**:
   - Dooro sanadka aad rabto (tusaale: Dhammaan, 2026, 2025, 2024, 2023, 2022, 2021, 2020 & Ka Hor).
   - Qeybta Dropdown-ka iyo Badhamada fudud (Quick Chips) oo tirada filimada sanadkaas tusinaya.

4. **Shaandhaynta Qeybaha (Genre Filter)**:
   - Af-Soomaali, Action, Drama, Majaajilo (Comedy), Musalsal, Sci-Fi, Naxdin (Horror).

5. **Soo Gelinta Filimada Cusub ("+ Ku Dar Filim")**:
   - Magaca filimka (Title).
   - Nooca filimka (Genre).
   - Sanadka iyo Taariikhda buuxda (Release date).
   - Qiimeynta (Rating: 1 - 10).
   - Muddada (Duration) & Agaasimaha (Director).
   - Sawirka poster-ka (URL toos ah ama soo geli fayl sawir ah: File Upload).
   - Link-ga muuqaalka / trailer-ka (YouTube ama MP4).
   - Faahfaahinta sheekada (Description).
   - Preview toos ah (Live Preview) inta aad foomka qorayso.
   - Xogta waxaa lagu keydiyaa LocalStorage-ka biraawsarkaaga.

6. **Muuqaalka Daawashada (Video Modal Player)**:
   - Daawo trailer ama filim buuxa oo tayo sare leh (HD / 4K).

7. **Keydinta & Soo Celinta Xogta (Backup & Export)**:
   - Dhoofi xogta oo dhan adoo hal gujin ku soo degsanaya fayl JSON ah.
   - Dib u celi xogtii asalka ahayd (Reset).

---

## 🚀 Sida Loo Shido (How to Run)

Waxaad ku shidi kartaa 2 hab oo aad u fudud:

### Habka 1: Node.js Server (Lagula talinayaa)
Fur terminal-ka ama PowerShell folder-kan dhexdiisa, ka dibna qor:
```bash
node server.js
```
ama
```bash
npm start
```
Ka dib biraawsarkaaga ka fur: **`http://localhost:3000`**

### Habka 2: Toos u fur (Direct Browser)
Kaliya laba jeer ku dhufo faylka **`index.html`** si uu biraawsarkaagu toos ugu furo!
